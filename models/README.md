# Hand Landmarker model

`hand_landmarker.task` is the pretrained Google MediaPipe Hand Landmarker asset used by this application, not a model trained by this project's author.

- Documentation: https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker
- Model distribution: https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/latest/hand_landmarker.task

Consult the model publisher's applicable terms before redistributing or using the asset. The application source and bundled dictionary have separate provenance.
